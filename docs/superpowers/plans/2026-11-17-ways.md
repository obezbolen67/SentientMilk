# Her Ways Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** She keeps if-then ways of doing things (told, decided, fallen into) that hold in every chat, strengthen as she keeps them and are reviewed in her sleep.

**Architecture:** `mind/ways.py` holds the ways (like `people.py`); `Mind` saves them, shows them as `## YOUR WAYS` through the session snapshot, gives them to THINK and reviews them once a night (`[mind:ways]`); a `ways` toolkit (part of her) keeps and drops them; API, panel and MilkChan show them.

**Tech Stack:** Python 3.12, SentientMilk framework (Textual panel), MilkChan (PySide6).

**Spec:** `docs/superpowers/specs/2026-11-17-ways-design.md`

## Global Constraints

- Release 0.34.0: pyproject, `__init__.__version__`, `extension/manifest.json` together.
- No code gates: nothing refuses her tools or urges because of a way.
- Strength: told/decided start 0.5, habit 0.3; kept +0.25 x (1 - s); broken x 0.85; unused 30 days x 0.95 a night; under 0.1 gone; shown as a habit from 0.7.
- `memory_save` stays this chat only; `ways_keep` is for every chat from now on.
- New MilkChan UI imports must be [project] deps (none expected).

## Review Focus

- A way name given with spaces or capitals ("Sign Replies") must update the same way, not add a twin: test in Task 1.
- The nightly answer naming a way she does not have, or malformed JSON, must change nothing: test in Task 4.
- Dropping a way that does not exist answers plainly, no error: test in Task 3.
- A chat's cached prompt changes only when her ways change: test in Task 2.
- A stand-in brain without a store (simulations) must still consolidate: Task 4 wraps the review like people.
